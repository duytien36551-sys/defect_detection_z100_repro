# DMA BRAM 的独立被动监测

> 历史实验归档（说明更新：2026-11-03）。本目录保存早期组件试验的条件和边界，不是最新 12 路/ACP 整机的操作入口，也不代表本次重新执行。旧 `tools/validate_z100_*.py`、绝对工程路径和盘符映射依赖原完整实验环境，本复现包不提供这些归档套件的独立可执行闭包。

当前可迁移检查入口为在**本包根目录**执行 `python -B sim/run_rtl.py --check`，详见 [当前 RTL 说明](../../../../../readme.md) 和 [九项回归范围](../../../../../reproduction.md)。当前九项 runner **不执行本目录的历史 DMA/候选试验**，其输入检查通过也不能更新本目录历史结论。

`bram_collision_observer.sv` 在 XPM 的 clka 上升沿、NBA 更新之前采样实际存储接口，检查有效写 `ena && wea[0]` 与有效读 `enb` 的同址访问。启用访问时的未知地址和控制也单独计错。该配置为公共时钟、无 ECC、整字写、WAKEUP_TIME=0；不依赖厂商关闭的碰撞消息/断言，也不依据外层 AXIS 握手推断存储访问。

`bind_bram_observers.sv` 不修改厂商文件，按已定位的两组参数筛选。验收还要求恰好两个输出，且完整路径分别位于 MM2S/S2MM 的 `I_DATA_FIFO/blk_mem/...gen_sdpram.xpm_memory_base_inst`，不接受其它 FIFO 替代。

开头 64 个时钟沿属于全局初始化，不计入访问/未知值检查；单列该窗口内已知有效写数，正式场景要求为零。此后复位不屏蔽同址检查。复位只清除回卷历史，避免将复位后的地址归零误计为自然回卷；原始复位周期和期间读写数均输出。`regceb` 影响输出寄存器，不作为 RAM 存储读使能。

`tb_bram_observer_selftest.sv` 独立驱动：有效同址、复位中同址各触发一次，活动未知地址触发一次；同时异址、关闭访问、分别关闭 ENA/WEA 都作对照，另检查读写回卷。预期诊断只在该自检实例中允许，实际 IP 实例会输出 FAIL。

`tb_z100_dma_bram.sv` 是历史跨页 TB 的新副本。仅改顶层名、增加八轮正常流量入口、使正常子任务返回、将 LAST 历史记录扩到 2048 拍并增加容量检查；原有整数参考、跨页突发、缓冲边界、AXI/AXIS 稳定性、复位和重载检查全部保留。历史 TB 不改。八轮分别验证 32 个有符号结果，合计 256 个结果检查，复用同一组向量用于指针状态覆盖。

历史场景包括 `selftest`、`wrap`、`read_reset`、`write_reset`、`rbackpressure`。

旧场景标识见下文；重跑这些归档场景需另行恢复并核对原实际 IP 导出、runner 和工具环境。

runner 为每例新建目录、快照输入并记录工具命令/日志哈希，重新编译和 elaborate，xelab 使用 2 个线程。集成场景仅在 X: 空闲时映射已保留的短路径导出，结束时核对归属并清理。HP0 是一读一写 outstanding 的行为端点，不是 PS7/物理 DDR。

八轮例要求两个实例的同时读写、读写自然回卷均非零，并各覆盖全部 128 个地址；复位/背压例保留各自原始访问计数，不强求短响应 FIFO 在每一例都有同时读写。RAM 访问数是内部存储事件，恢复时不要求等于 AXI 有效负载拍数。有限场景内没有碰撞不等于全状态证明，REQP-181、LUTAR-1、RTSTAT-10 不因此关闭；尚无时序网表或实板碰撞压力验收。
