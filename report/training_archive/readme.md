## 论文参数与本地设置

论文：Zhao et al., A Defect Detection Algorithm for Optoelectronic Detectors Utilizing GLV-YOLO, Micromachines16(3):267,2025，doi:10.3390/mi16030267。表2明确300轮、batch32、SGD、lr0=.01；本文未明确可复现的网络输入尺寸、初始化和全部超参。用户已同意本地imgsz640，未公开参数明确记为本实验选择。

|参数|本实验|依据|
|---|---|---|
|结构|原版YOLOv8n九类|沿用用户模型，不是论文GLV改进结构|
|初始化|随机、无COCO或旧缺陷权重|沿用从零训练要求|
|epochs|300|论文表2|
|optimizer/lr0|SGD / .01|论文表2|
|输入|640|用户明确确认，本地选择|
|物理batch|16|32内存检查失败；16完整步骤通过|
|nbs/梯度累积目标|32 / 2步|目标有效batch32，预热按框架规则，并非物理batch32|
|momentum/weight_decay|.937 / .0005|本地框架默认|
|学习率|线性衰减，lrf=.01|本地选择|
|warmup|3轮、bias初始lr=.1|本地框架设置|
|在线增强|mosaic1（末10轮关闭）、scale.5、translate.1、fliplr.5、HSV.015/.7/.4|本地框架设置，另有已生成离线增强|
|损失权重|box7.5/cls.5/dfl1.5|本地默认CIoU/DFL体系，未引入论文WIoU|
|选模|新验证集AP50:95最高轮|固定规则，不调测试集|

由于结构、未公开参数和物理batch限制，这属于“参考论文公开训练参数的v8n实验”，不能宣称完全复现GLV-YOLO。
