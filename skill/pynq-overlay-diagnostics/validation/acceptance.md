- Python 3.12 Windows环境下，32项测试通过：17项Overlay/DMA契约检查，7项运行采集器软件替身测试，8项notebook静态检查。测试覆盖字节上限、dtype、偏移与容量、非DRE对齐、层级IP、缺参、SG/micro模式、器件冲突、无效元数据、输出不覆盖输入、download=False及notebook代码不执行。
- 六个可重跑静态示例通过预期结果核对：7020图像块、信号向量、超长图像、7100迁移、7100盘点、公开PYNQ缩放notebook。BLOCKED/INCOMPLETE是示例应当产生的诊断，不将缺项补成成功。
- 两套完整原始HWH/XSA亦执行了同一检查脚本，而不只运行分发的简化片段；结果见full_7020_audit.json、full_7100_audit.json。7100标准AXI DMA缺失被正确保留。
- skill-creator的quick_validate通过；支持Python3.9语法检查，但本轮实际运行环境为Python3.12，Linux和Python3.9未实跑。
- 当前电脑无PYNQ运行时，实际执行采集器返回unavailable；没有把软件替身返回值写成板端结果。

详细软件结果见software_validation.json，六示例见examples_summary.json。报告中的硬件执行均为false。另完成两项独立智能体使用检查，主线程已查看实际配置、JSON与报告：新建float32信号任务正确计算16,384/8,192字节并保留缺失证据；公开PYNQ缩放notebook识别加载和等待风险，未执行代码。见forward_summary.json与forward_*目录。这是同一环境中的智能体复用检查，不是外部团队或实板测试；信号检查者曾误读旧int16案例，因此不称完全盲测。独立ZIP在隔离目录解压后再次通过32项测试、6项演示、结构校验及全部文件哈希检查，见portable_acceptance.json。

## 未声明的能力

没有在两块物理板卡上运行PYNQ推理，没有改写现有7020/7100裸机工程为PYNQ控制链，没有验证TLAST、真实DMA事务、输出质量、性能或所有板卡兼容。软件诊断能在新板卡元数据上运行，不等于那个bitstream可直接跨器件加载。提供的运行采集器实际PYNQ分支只做软件替身测试，需用户在其PYNQ系统内运行才能取得该环境记录。

本技能可作为符合已知通用条件的独立PYNQ诊断技能提交评审；具体加分和完整细则由赛方确定。
