# PS/PL 划分与性能优化

根据实测耗时和实际传输量选择优化项，同时评估计算、端口、带宽、资源与时序。

先读取详细工作流（文件：references/workflow.md），按其步骤执行；这是本技能的主要操作说明。

## 材料发现与授权

优先从当前工程、配置、构建产物、日志及可访问聊天记录查找材料，核对身份与完整性。没有聊天访问能力时继续从工程证据取证，不要求用户重复搜集可访问资料。只有查找后仍有关键缺项、歧义或需要实体操作及必要授权时才询问。未生成的实测证据标为缺失，参考结果和计划不替代实测。

下载、初始化、板卡复位、持久存储写入和训练进程控制须由当前任务授权；加载技能本身不提供授权。可继续独立的只读检查，不扩大任务范围。

## 三：PS/PL 划分与性能优化

适用：换更大 FPGA、增加并行度、追求目标 FPS、ARM/传输成为瓶颈。

执行所需材料（由 Codex 优先自动查找）：绑定身份的实测 profiling、计时起止点、布线资源/时序、逐层 MAC、实际 DMA 字节数。

流程：
1. 列出传输、预处理、打包、DMA准备/等待/收尾、PL计算、重定标、非卷积、解码/NMS与返回；注明包含关系及测不到的部分。
2. 目标帧周期 = 1000/目标FPS 毫秒。分别检查计算、搬运和后处理是否超过预算。
3. 优先消除实测瓶颈。考虑窗口/特征复用、权重生命周期、传输重叠、重定标或后处理迁移；不得声称当前已有的复用又被“新增”。
4. 同时估算尾通道/尾位置、流水排空、装载、存储端口和带宽。静态理想周期只作为下界。
5. 独立候选先过一致性和时序，再上板比较。控制模型、输入和计时范围；报告样本量、P50/P95及连续吞吐。

提示词：

> 根据实测分项耗时、实际传输量和布线报告，选择下一项 PS/PL 优化。说明计算/带宽/存储端口限制、最小实现范围、数值一致性条件和实测方法。候选估算与已上板结果分开；资源占用不等于忙碌率。

输出：瓶颈证据、一个可执行优化实验、计算与带宽预算、验收条件。失效条件：仅有单帧时间时不能给出P95；无真实布线时不能保证频率。

历史经验和本次核验范围见经验说明（文件：lessons.md）与验证摘要（文件：../validation/review_summary.json）。
