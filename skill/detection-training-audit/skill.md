# 数据质量、量化汇报与训练收尾

检查增强图来源隔离、冻结划分与选模规则；使用同一权重汇报质量，按授权检查收尾。

先读取详细工作流（文件：references/workflow.md），按其步骤执行；这是本技能的主要操作说明。

## 材料发现与授权

优先从当前工程、配置、构建产物、日志及可访问聊天记录查找材料，核对身份与完整性。没有聊天访问能力时继续从工程证据取证，不要求用户重复搜集可访问资料。只有查找后仍有关键缺项、歧义或需要实体操作及必要授权时才询问。未生成的实测证据标为缺失，参考结果和计划不替代实测。

下载、初始化、板卡复位、持久存储写入和训练进程控制须由当前任务授权；加载技能本身不提供授权。可继续独立的只读检查，不扩大任务范围。

## 历史证据与能力边界

需要案例时读取经验来源（文件：references/lessons.md）。材料为历史记录的脱敏示例与核验说明，记录了失败、修正和限制，不代表当前运行状态。旧板地址、时钟、类别和质量门槛不可直接移植。历史聊天中的模型分工不构成当前调用要求。

1.0.0历史工作流验证：两个本地材料案例已完成独立行为执行与主线程证据复核，跨项目验证限于所记录的静态材料审查。结果与范围见验证摘要（文件：validation/review_summary.json）。没有通用PYNQ跨板结论。仅在任务需要时读取案例证据。

## 交付

输出权重与划分身份、分集合/后端质量及完整逐类证据、正常图误报率可评估性和收尾状态。

需要完整报告时使用报告模板（文件：assets/validation_report_template.md），只填写本次任务相关部分，其余标记未评估。

已有结构化 JSON 报告时，可按需运行只读质量报告审计与历史报告适配工具（文件：references/automation.md），复算类别计数与固定工作点微平均，核对历史训练 CSV 的轮次连续性及声明选模一致性；工具通过不代表业务验收通过。

测试不参与选模和调参；固定工作点微平均不与自动工作点宏平均混用；无正常图时不可评估；断点不全或进程身份不明时不停止训练。

运行示例和明确限制见本技能说明（文件：readme.md）。

## 组合任务与工具边界

先判断本次问题属于身份、输出差异、性能、DMA现场或训练质量；跨领域问题按证据依赖依次检查。仅在需要时加载其他已安装技能；缺少其他技能时按本工作流完成可做部分。自动化工具只验证声明的输入契约与可计算事实，材料发现和工程结论仍须核对原始证据。新版工具验证见自动化说明（文件：references/automation.md），历史案例不自动算作新工具的验收。

## 真实材料适配

当前工程材料若符合自动化说明（文件：references/automation.md）列出的格式，优先使用对应材料适配器，保存输入SHA-256、字段映射、命令和原始输出。未知格式先核对语义再转换；不能用默认值补出成功，也不能将历史记录复算称为新实板或训练结果。

# 工作流与使用方法

以下提示词是本次从经验整理的模板，不是历史聊天原文。参数由 Codex 优先从当前工程、配置及可访问记录中查找并核对，例子不代表所有模型都采用 INT8 或同一门槛。

## 五：数据质量、量化汇报与训练收尾

适用：增强数据重新划分、训练效果报告、冻结选模、用户要求某轮收尾。

执行所需材料（由 Codex 优先自动查找）：冻结划分、来源关系、类别计数、选模规则、逐轮日志、权重/断点和评价协议。

流程：
1. 按已知原图来源组隔离增强图；区分图片数、来源组数与真实器件/批次数，未知独立性如实记录。
2. 固定验证集选模；测试集仅在冻结后按授权用于验收，不能为提高测试成绩调阈值或筛图。
3. 同一权重报告AP50/AP50:95、固定阈值P/R/F1及TP/FP/FN、逐类AP/召回/目标数；自动工作点与固定微平均不混用。
4. 正常图误报率单独计算，无正常图写不可评估。记录置信度、NMS、匹配规则、max_det与类别过滤。
5. 浮点、离线整数参考和实板结果分开，量化损失用百分点；基线比较要求同一划分和评价口径。
6. 若用户要求完成某轮后停止，先定义完整轮次与断点可读取条件；保留优化器、学习率状态、EMA和随机状态。只控制目标实验，不据界面分母推断必须续训。
7. 中途收尾是否改变学习率计划必须明确记录；保留原计划是本项目选择，不作为通用要求。

提示词：

> 根据冻结划分和既定选模规则，用同一权重生成质量报告，分开各集合、浮点/INT8/实板与正常图误报率。说明增强相关性、历史曝光和基线可比性。若涉及训练收尾，仅在授权轮次的完整断点确认后执行，并记录保留或修改学习率计划的决定。

输出：按报告模板填写的 JSON/Markdown 与权重身份。退出条件：训练进程身份不明、断点不完整或无停止授权时，不终止进程；仍可只读检查。

历史经验和本次核验范围见经验说明（文件：lessons.md）与验证摘要（文件：../validation/review_summary.json）。


## 本次复核补充

把断点状态、权重选择、验证复评及业务验收分别列出。原训练输入尺寸与验证rect实际填充尺寸可能不同，应同时报告。逐轮CSV与冻结权重复评可能是不同评价口径；核对已有选模规则，不为适配最终报告重新选模。没有权重二进制时，哈希仅是报告声明。正常图、独立器件/批次和未执行后端分别说明缺项；完整逐类表不可省略。
