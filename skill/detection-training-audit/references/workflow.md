# 工作流与使用方法

以下提示词是本次从经验整理的模板，不是历史聊天原文。参数由 Codex 优先从当前工程、配置及可访问记录中查找并核对，例子不代表所有模型都采用 INT8 或同一门槛。

各节的“执行所需材料”是工作流的依赖清单，不是要求用户手动提交的清单。Codex 应先自动查找材料、核对身份与完整性，再执行已授权的检查。只有经过查找仍无法获取材料、无法消除关键歧义，或需要用户完成实体操作及补充必要授权时，才提出具体问题。缺失的实测证据不得编造，计划和参考结果不得替代实测。

## 五：数据质量、量化汇报与训练收尾

适用：增强数据重新划分、训练效果报告、冻结选模、用户要求某轮收尾。

执行所需材料（由 Codex 优先自动查找）：冻结划分、来源关系、类别计数、选模规则、逐轮日志、权重/断点和评价协议。

流程：
1. 按已知原图来源组隔离增强图；区分图片数、来源组数与真实器件/批次数，未知独立性如实记录。
2. 固定验证集选模；测试集仅在冻结后按授权用于验收，不能为提高测试成绩调阈值或筛图。
3. 同一权重报告AP50/AP50:95、固定阈值P/R/F1及TP/FP/FN、逐类AP/召回/目标数；自动工作点与固定微平均不混用。
4. 正常图误报率单独计算，无正常图写不可评估。记录置信度、NMS、匹配规则、max_det与类别过滤。
5. 浮点、离线整数参考和实板结果分开，量化损失用百分点；基线比较要求同一划分和评价口径。
6. 若用户要求完成某轮后停止，先定义完整轮次与断点可读取条件；保留优化器、学习率状态、EMA和随机状态。只控制目标实验，不据界面分母推断必须续训。
7. 中途收尾是否改变学习率计划必须明确记录；保留原计划是本项目选择，不作为通用要求。

提示词：

> 根据冻结划分和既定选模规则，用同一权重生成质量报告，分开各集合、浮点/INT8/实板与正常图误报率。说明增强相关性、历史曝光和基线可比性。若涉及训练收尾，仅在授权轮次的完整断点确认后执行，并记录保留或修改学习率计划的决定。

输出：按报告模板填写的 JSON/Markdown 与权重身份。退出条件：训练进程身份不明、断点不完整或无停止授权时，不终止进程；仍可只读检查。

历史经验和本次核验范围见经验说明（文件：lessons.md）与验证摘要（文件：../validation/review_summary.json）。


## 本次复核补充

把断点状态、权重选择、验证复评及业务验收分别列出。原训练输入尺寸与验证rect实际填充尺寸可能不同，应同时报告。逐轮CSV与冻结权重复评可能是不同评价口径；核对已有选模规则，不为适配最终报告重新选模。没有权重二进制时，哈希仅是报告声明。正常图、独立器件/批次和未执行后端分别说明缺项；完整逐类表不可省略。
