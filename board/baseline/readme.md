# 7Z100 第一版跑通基线

此目录保留2026-10-23首次完成整网实板推理的历史基线：YOLOv8n PIN9 epoch108、640×640输入。它与当前epoch200模型、独立网络修复固件以及后续源码重建产物身份不同；旧epoch108模型数据已从本包移出，`baseline_identity.json`中的路径和SHA只用于追溯。

当前部署和检测入口使用epoch200模型；`baseline_identity.json`中的旧epoch108路径和SHA仅供追溯，不代表旧模型、bit、ELF或XSA仍随包提供。

163 个节点执行完成，94 次 LOAD、6319 次 RUN；613200 字节 INT8 检测头与参考逐字节一致，差异为零，检测数为 2。单图一致性不是全数据集精度验收。

result.json、pipeline_diagnostics.bin、raw_heads_padded.bin 为首次成功完成的原始采集结果；first_frame_summary.json 保存完整逐节点计时及来源哈希。baseline_identity.json 保存该基线记录时从源文件重算的哈希及身份，原始记录不改写为其他模型或其他版本的成绩。

不同模型、不同计时范围的结果不能直接据此计算同条件加速比。
