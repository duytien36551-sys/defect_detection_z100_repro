# Z100 SD 卡启动文件（2026-11-03 网络修复版）

本目录 BOOT.BIN 已替换为修复版，包含 FSBL、原 FPGA 位流、PIN9 epoch200/640 应用和内嵌模型。只需要复制 BOOT.BIN，不必复制说明与 JSON，不需要另放权重或 Linux 文件。

## 替换步骤

1. 关闭板卡电源，取出 SD 卡。
2. 用本目录的新 BOOT.BIN 覆盖 FAT32 分区根目录的旧 BOOT.BIN，安全弹出 SD 卡。
3. 插回底板 PS Micro SD 卡槽；BOOT_CFG 两个开关均为 OFF（以厂家标识为准）。
4. 网线连接 PS 网口，电脑地址 192.168.10.1/24，板卡地址 192.168.10.2:5001。
5. 重新上电启动，在桌面“Z100光电缺陷检测”中检查连接，再导入固定图片检测。检查连接可以重复执行。

## 修复及验证范围

已确认并修复百兆协商时发送参考时钟仍为千兆配置，以及 HELLO-only 检查连接断开后旧服务进入故障停止这两个问题。

同一修复固件已经通过 JTAG 实板连续握手检查、空 TCP 连接关闭、单图推理和推理后再次握手；单图结果与已有参考一致。采用默认 FULL 缓存策略，没有注入 scoped 资格收据。

BOOT.BIN 已真实生成并读取，启动头、分区校验和与实测 ELF 对应均通过。新镜像还需按上述步骤替换 SD 并断电冷启动，尚未将其写成冷启动已验收。旧 SD 热复位曾停在 FSBL 的 PCAP 等待，因此请执行断电重新上电。

当前板卡已通过 JTAG 临时加载修复版；若 SD 内仍是旧文件，断电后会重新加载旧版，必须替换卡内 BOOT.BIN。

本轮仅验证连接和固定单图回归，不代表重新测得数据集准确率或持续 FPS。SHA-256、实际测试与限制见同目录“生成与校验记录.json”。源代码、重建入口与详细证据在主工程 deployment/board_support/z100_sd_network_fix_v1。
